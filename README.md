# Autospend Legal Policies Website

This is a clone of the Autospend policies website, containing all legal documents and policies for Stable Payments Inc.

## Structure

- **index.html** - Main landing page with policy navigation menu
- **styles.css** - Styling for all pages matching the original design
- **Policy Pages:**
  - terms-of-service.html
  - privacy-and-data-policy.html (merged: privacy, data use, and cookies)
  - information-security-policy.html
  - risk-management-policy.html
  - card-user-agreement.html
  - consumer-card-terms-us.html
  - consumer-card-terms-international.html
  - electronic-communications-notice.html (E‑Sign and Electronic Communications Notice)

## Features

- Clean, modern design matching the original
- Responsive layout for mobile and desktop
- Easy navigation between policies
- Professional typography and spacing
- Accessible color scheme

## Viewing the Site

Simply open `index.html` in a web browser to view the policies website locally.

## Content

The Terms and Conditions page contains the exact content from the original Autospend policies site. Other policy pages have been populated with comprehensive, professional content appropriate for a financial services platform.
